# omarchy-stuff

Personal tools, scripts, and customizations built for [Omarchy Linux](https://omarchy.org/).

## Projects

- [`omarchy-web-tab-focus`](./omarchy-web-tab-focus/README.md) — Multi-browser Native Messaging host, CLI, and Manifest V3 extension so Hyprland keybindings can jump straight to an existing browser tab (or open one cleanly) instead of spawning duplicates.

See each project folder's `README.md` for installation and detailed usage instructions.
